# Licensing: a decision for the project owner

No licence file is included on purpose. Until one is added, the default is "all rights reserved", which is the safe choice while approvals are pending.

Parts and who might own them (confirm with LSE IDEAS and the other authors):
- **Code** (`src/template.html`, `build.py`, tests). Derived from the Pakistan 2047 randomiser engine. Common choices: MIT or Apache-2.0 for code.
- **Written scenario content** (`src/content.json`, `src/site.json`). Common choice: CC BY 4.0 (share with credit) or CC BY-NC-SA 4.0 (non-commercial, share alike).
- **Pictures** (`src/img/`). Generated with Leonardo.ai. Check the Leonardo terms for your plan on ownership, commercial use and redistribution, and whether the open-source licence you pick can legally cover them. Keep the "AI-generated illustration" label.
- **Flag logo**. The Singapore flag is drawn as a simple vector; state flags are generally free to depict, but check any local rules before commercial use.

Add a `LICENSE` file and a short licence section to the README once decided.
